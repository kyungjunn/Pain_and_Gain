# Pain & Gain

3D 로그라이크 액션 디펜스. 적을 처치하고 증강을 골라 성장하며, 선택형 위험 도전으로 추가 보상을 노립니다.

**캐릭터 선택 → 전투·성장 → 사망 → 결과 확인 → 재시작**

## 다운로드 및 실행

**Windows x64 · Google Drive ZIP 배포 예정**

1. Google Drive에서 Windows 빌드 ZIP을 다운로드합니다. 링크는 배포 시 추가됩니다.
2. ZIP 전체를 압축 해제합니다.
3. 압축을 푼 폴더에서 게임 실행 파일(`.exe`)을 엽니다.

## 캐릭터

| 캐릭터 | 역할 | 기본 공격 | Q | E | R |
| --- | --- | --- | --- | --- | --- |
| 닌자 (Ninja) | 기동 | 쿠나이 | 화둔 | 돌진 | 뇌명 |
| 검사 (Knight) | 근접 | 베기 | 전방 휘두르기 | 돌진 베기 | 광역 참격 |
| 마법사 (Wizard) | 원거리·군중 제어 | 마력탄 | 중력핵 | 공명 마법진 | 마력 폭주 |

## 주요 기능

- **전투** · 적 순찰·추격 · 시간에 따른 스폰 강화 · 레벨별 적 해금 · 보스 약점
- **성장** · 처치 경험치 · 레벨업 · 증강 카드 선택 · 스킬 중첩 · 궁극기 게이지
- **증강** · 공격력·체력·이동속도 · 흡혈·거대화·화염 오라 · 닌자·마법사 전용 강화
- **길잡이** · 4단계 · 처치·Q 적중·첫 증강·목표 추적
- **일반 퀘스트** · 시작 예고 · 제한 시간 · 경험치·회복 보상 · 실패 페널티 없음
- **위험 도전** · 도전 구역 진입 · 거인 사냥 · 성공 시 증강 선택권 · 실패 시 지정된 증강 중첩 1단계 감소
- **결과 화면** · 생존 시간 · 처치 수 · 레벨 · 획득 증강

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 | 시점·조준 |
| 마우스 왼쪽 버튼 | 기본 공격 |
| `Space` | 점프 |
| `Q` / `E` | 스킬 |
| `R` | 궁극기 |
| `Tab` | 능력치 창 |

## 개발 환경

**Unity 6000.3.10f1 · C# · URP · Cinemachine · Input System · AI Navigation**

```bash
git clone --branch dev https://github.com/kyungjunn/Pain_and_Gain.git
```

Unity Hub에서 프로젝트를 열고 `Assets/Scenes/IntroUI.unity`를 실행합니다. 캐릭터별 스킬 테스트는 `Assets/Scenes/CharacterTest.unity`에서 할 수 있습니다.
